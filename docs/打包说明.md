# 文件标签浏览器 Tauri 2.x 打包说明

## 一、打包命令

进入项目根目录，执行：

```
cd "d:\notebook\code\work\file-tag-browser-v2"
npm run tauri:build
```

首次打包会下载并编译 Rust release 版本（含 rusqlite 静态链接 SQLite），耗时较长，通常需要 10 到 30 分钟。后续修改重新打包只做增量编译，速度很快。

## 二、产物位置

打包完成后，产物位于 `src-tauri\target\release\` 目录：

- `src-tauri\target\release\file-tag-browser-v2.exe`：单文件可执行程序（自带 SQLite，体积约 15 至 20 MB）
- `src-tauri\target\release\bundle\nsis\`：NSIS 安装包（.exe 安装器）
- `src-tauri\target\release\bundle\msi\`：MSI 安装包（仅在配置了 msi 目标时生成）

## 三、当前 bundle 配置

`src-tauri/tauri.conf.json` 中 bundle 节点配置如下：

```json
"bundle": {
  "active": true,
  "targets": ["nsis"],
  "icon": ["icons/icon.png"]
}
```

当前仅配置了 nsis 输出。如果需要 msi 安装包，将 targets 改为：

```json
"targets": ["nsis", "msi"]
```

## 四、打包前确认项

打包前需要确认以下项目都已就绪：

1. 图标资源存在：`src-tauri/icons/icon.png` 与 `src-tauri/icons/icon.ico`
2. capabilities 配置正确：`src-tauri/capabilities/default.json`
3. `src-tauri/Cargo.toml` release 配置已优化（lto、strip、opt-level）
4. tags.db 文件路径：放在 exe 同级目录，无需额外资源声明
5. 应用标识符 identifier 已设置为 `com.filetag.browser`
6. 产品名称 productName 与窗口标题一致

## 五、版本号调整

修改版本号时，需要同步更新两处：

- `src-tauri/tauri.conf.json` 中的 `version` 字段
- `package.json` 中的 `version` 字段

## 六、可选打包方式

### 仅生成单 exe，不打包安装器

```
npx tauri build --bundles nsis --no-bundle
```

### 指定打包目标

```
npx tauri build --bundles nsis
```

### 仅生成 msi

需要先在 `tauri.conf.json` 中将 targets 改为 `["nsis", "msi"]`，然后执行打包命令。

## 七、便携版与安装版区别

- 单 exe（target\release\file-tag-browser-v2.exe）：用户双击即可运行，tags.db 与 exe 同目录存储，适合个人使用
- NSIS 安装包：会引导用户选择安装路径、创建桌面快捷方式与开始菜单项，tags.db 默认放在用户选择的安装目录下
- MSI 安装包：适合企业部署，支持组策略和静默安装

## 八、打包常见问题

### MSVC 链接错误

如果出现 link.exe 相关报错，确认已安装 Microsoft Visual Studio 2022 Build Tools（含 C++ 桌面开发组件）。

### 图标错误

如果出现 `icons/icon.ico` 相关错误，确认 `src-tauri/icons/` 目录下同时存在 `icon.png` 和 `icon.ico` 两个文件。

### WebView2 缺失

目标机器如果是 Windows 10 早期版本且未安装 WebView2 Runtime，安装包需要在 Tauri 配置中启用 `bundle.windows.webviewInstallMode` 选项，引导用户自动下载安装。

### 首次编译慢

首次编译会下载约 400 个 Rust crate 并编译 rusqlite（内含 C 语言 SQLite 源码），属于正常现象。

## 九、打包后验证清单

打包完成后，按以下顺序验证：

1. 双击 exe 能正常启动窗口
2. 关闭后重新启动，数据不丢失
3. 在 exe 同级目录能找到 tags.db 文件
4. 关闭 exe 后 tags.db 能被复制走（确认未被独占锁）
5. 拷贝整个目录到其他机器上能正常运行
